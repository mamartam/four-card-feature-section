# Four card feature section
This project was created based on a Frontend Mentor [https://www.frontendmentor.io/] challenge. The layout and design idea come from Frontend Mentor, while the code implementation is my own.

## 🛠 Technologies
- HTML5 — semantic markup for page structure
- CSS3 — styling, layout, and responsive design
- Flexbox — layout of feature cards
- Media Queries — responsive behavior for different screen sizes
- Google Fonts (Poppins) — typography
- BEM methodology — class naming for better code readability and scalability

## 🧩 Development Process

First, I reviewed the provided design and style guide to understand the layout, color palette, typography, and responsive requirements.

I started by creating the HTML file and building the basic page structure. I used semantic HTML elements such as header, main, and section to clearly separate the page content. All text and images were added at this stage to ensure the structure was complete before moving on to styling.

Next, I created a separate CSS file and connected it to the HTML document. At the beginning of the styling process, I applied global styles, including box-sizing: border-box, and set up the base font, font size, and colors according to the style guide.

For the layout of the feature cards, I used Flexbox, as it was the most suitable solution based on my current knowledge. I organized the cards into columns and adjusted their alignment for different screen sizes using media queries to ensure responsiveness.

Each feature card was styled as a reusable component. I used modifier classes to apply different top border colors to the cards, which helped keep the CSS clean and easy to maintain.

Throughout the development process, I continuously compared the implementation with the original design and made small adjustments to spacing, typography, and alignment to achieve a result as close to the mockup as possible.

## 📚 What I Learned
- How to structure a web page using semantic HTML (header, main, section) to improve readability and accessibility.
- Practical experience with Flexbox for building responsive layouts and aligning elements.
- How to apply media queries to adapt the layout for smaller screen sizes.
- How small details such as spacing, typography, and alignment can significantly improve the overall look and usability of a page.
- Gained a better understanding of planning the layout before writing code to make the development process more efficient.

## 🚀 How It Can Be Improved?
- Rebuild the layout using CSS Grid to better handle the complex card arrangement on larger screens and reduce the need for multiple wrapper elements.
- Introduce CSS custom properties (variables) for colors and spacing to make the styles easier to maintain and update.
- Add subtle hover and focus states for the feature cards to improve user interaction and visual feedback.
- Further optimize the layout by refining spacing and typography to make the design even closer to the original mockup.
